# Glossary

LMEP defines its own terminology to describe the various components, structures and operations of the protocol. These terms are formally defined within the specification to ensure consistency and avoid ambiguity when interpreting and implementing the protocol.

^^__LMEP__^^ - Lightweight Message Exchange Protocol, the name of the protocol I am submitting.
^^__Reference implementations__^^ - Alongside a specification for LMEP, there are also python programs which implement LMEP's minimum requirements to demonstrate its functionality. Since LMEP is a client-server protocol, there will be an implementation for the client and an implementation for the server, the word "implementations" referring to both. These may be referred to as "minimum viable implementations".
^^__Chathome__^^ - An organisational unit hosted by an LMEP server. Each chathome maintains its own collection of chatrooms and members.
^^__Chatroom__^^ - A communication space contained within a chathome. Each chatroom maintains its own message history.
^^__Homeowner__^^ - The owner of a chathome.
