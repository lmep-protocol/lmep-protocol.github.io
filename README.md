# LMEP Specification

This is the repo containing the properdocs source for lmep-spec.github.io

## Building the site

Ensure you have the following installed:

- git
- properdocs

Clone the repo:

```sh
$ git clone https://github.com/lmep-protocol/lmep-protocol.github.io 
```

Then, host the site locally:

```sh
$ properdocs serve
```

Once this command is run, the site will be available on `localhost:8000`.
